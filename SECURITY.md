# Security Policy

Sweep reads and deletes items in your photo library, so security and privacy bugs are taken seriously.

## Reporting a vulnerability

Please report privately using GitHub's [private vulnerability reporting](https://github.com/iamabhaymittal/Sweep/security/advisories/new). Don't open a public issue.

Include:
- what the issue is and its impact, for example deleting items without confirmation or sending data off the device
- steps to reproduce
- the iOS version and device

You'll get a reply within a week. Fixes are released as soon as practical, and reporters are credited unless they'd rather not be.

## Supported versions

Only the latest version on `main` receives fixes.
